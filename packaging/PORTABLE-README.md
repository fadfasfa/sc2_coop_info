# SC2 Coop Info 简中隔离便携测试版

这是未签名的个人测试构建，不是原作者的正式 Release。此包的生成不等于自动验收或真人验收通过；在主代理明确给出安全检查结论前不要运行。

## 使用与回退

1. 退出原版 SC2 Coop Info。原版和本包轮流运行，避免全局快捷键冲突。
2. 将整个目录解压到新的可写目录，保留 EXE、data 和 LICENSE 的相对位置。不覆盖原版、不复制原版设置或缓存。
3. 启动 `SC2_Coop_Info_ZhCN_Portable.exe`。首次启动只在 EXE 同级创建 `profile`，默认读取空 `profile/Accounts`，不扫描真实 Accounts。
4. 主代理完成安全门后，仅选择用户明确指定的录像目录或其副本。录像、昵称、备注不会上传。
5. 验证简体中文切换、保存、退出重开、指定历史录像，再由用户完成普通合作和周突变各一局。记录开局玩家信息、结束自动统计、热键、悬浮窗、中文内容及当前/150%缩放。
6. 回退时退出便携版，并启动原版即可。无需卸载或改动原版。不要同时运行两版。

## 隔离边界

- 应用标识为 `com.fadfasfa.sc2coopinfo.zhcn.portable`；窗口类名具有 `ZhCNPortable` 后缀。
- 设置、缓存、日志、默认截图及 WebView2 数据位于 EXE 同级 `profile`。目录不可写或存在被拒绝的链接/重解析点时明确停止，不回退到原版 AppData。
- 自动更新和自启动插件未注册；更新下载/安装、自启动注册及 legacy 注册项清理的实现已移除或替换为无操作。即便旧设置要求启用，也不执行这些操作。
- Google Analytics 脚本及网络许可已移除。作者更新说明仍可从公开 GitHub API 读取；其正文不作翻译。
- 本包不含 MSI/NSIS，不注册安装项，不使用作者签名。
